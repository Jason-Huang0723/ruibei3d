# 瑞北 3D 導覽

花蓮縣瑞穗鄉瑞北國小與周邊（台9線、東輪機車行、林上商號）的 3D 模型，給慈幼山友團「出隊必修課 2：環境介紹」用。一個小人照必修2 的動線真的走一遍：大門、穿堂、一樓教室、樓梯、二樓、國幼班、禮堂，最後走到校外的雜貨店。

## 怎麼看

1. 下載這個 repo：右上角 **Code → Download ZIP**，解壓縮。
2. 用電腦的 **Chrome 或 Edge** 直接打開 `index.html`。
3. 第一次載入約 1–3 分鐘，地圖資料會即時從國土測繪中心和 OpenStreetMap 下載；之後會快取，開得比較快。

操作方式：

- 下方按鈕選場景：**開場、一樓、二樓、國幼班、禮堂、雜貨店**。按了就從頭播放，進度條可以拖。
- **▶▶ 全部連播**：六段接著播。
- **自由視角**：暫停播放，可以拖曳旋轉、滾輪縮放、右鍵平移，房間名稱會依距離顯示。
- **字幕・標籤**：開或關畫面上的說明字幕和標籤。
- **匯出影片**：輸出 1920×1080 的 MP4（30 或 60 fps），每個場景一個檔案，可以選要不要加字幕。需要電腦版 Chrome／Edge。

手機會自動切換成輕量模式。想強制切換，可以在網址後面加 `?q=low` 或 `?q=high`。

## 場景內容

| 場景 | 小人走的路 | 字幕重點 |
|---|---|---|
| 開場 | 空拍這一區，最後降到大門口 | 瑞北國小、台9線、東輪機車行、公車站、祥北路、林上商號 |
| 一樓 | 大門 → 穿堂 → 辦公室 → 走進四教 → 一路走到廁所 | 四教哥姐午休；不用教室垃圾桶、不動老師東西和黑板；教室復原 |
| 二樓 | 爬樓梯 → 會議室 → 校長室 → 圖書室 → 英語教室 → 五教、六教 | 早餐和吹風機、團本部和浴室、睡覺、行李、布簾、打呼專用 |
| 國幼班 | 穿過操場 → 門口脫鞋 → 進去 → 沿走廊到遊樂器材 | 睡覺、脫鞋；遊樂器材營期間禁止使用 |
| 禮堂 | 一樓東端 → 繞到靠操場的後門 → 進去走到舞台前 | 吃飯檢討營包早操；只走後門；舞台右邊電源、左邊庶務 |
| 雜貨店 | 校門 → 台9線往北 → 過馬路 → 祥北路 → 林上商號 | 送完小朋友回家後的雜貨店（3 倍速） |

走路的動畫進度和走過的距離綁在一起，腳步不會滑；起步、停下有加減速，轉彎和鏡頭都做了平滑。

## 原始碼

`index.html` 是由 `src/` 裡的檔案接起來的，改完執行 `python3 build.py` 重新產生。

| 檔案 | 內容 |
|---|---|
| `src/01_core.js` | 座標換算、圖磚下載、快取 |
| `src/02_terrain_ortho.js` | 地形、正射影像、去浮水印 |
| `src/03_buildings.js` | 房屋輪廓描邊與立體化 |
| `src/04_veg_roads.js` | 樹、道路 |
| `src/05_school.js` | 學校：教室、走廊、樓梯、家具、禮堂、國幼班、大門（`RB.ROOMS` 是各樓層房間表） |
| `src/06_character.js` | 小人、時間軸、跟拍鏡頭、字幕繪製 |
| `src/07_tour.js` | 六個場景的路線、鏡頭、字幕（要改台詞或路線改這裡） |
| `src/08_app.js` | 場景組裝、介面、匯出影片 |

## 內容怎麼做的

| 部分 | 來源 |
|---|---|
| 地面影像 | 內政部國土測繪中心 正射影像（PHOTO2），已自動去除「NLSC 2022」浮水印 |
| 房屋輪廓 | 國土測繪中心「通用電子地圖加值分棟建物框」（BUILDX），在瀏覽器裡描成多邊形 |
| 房屋高度 | 依面積推估 1–4 層，實際樓層沒有資料 |
| 道路、鐵路、地名 | OpenStreetMap |
| 地形 | Mapzen／AWS Terrain Tiles |
| 樹 | 從正射影像找出樹冠位置後隨機種樹，約 1/5 是檳榔樹 |
| 學校 | 社團雲端「瑞北國小場地平面圖.png」與分棟建物框對齊，再依舊版必修2 影片的口述補上二樓與各室用途，見 `docs/校園配置.md` |
| 小人 | three.js 範例模型 Xbot（Mixamo 動作） |

Google 地圖和高德都沒有用來建模，前者條款不允許，後者在台灣的資料很少。
