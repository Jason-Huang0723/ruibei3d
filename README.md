# 瑞北 3D

花蓮縣瑞穗鄉瑞北國小與瑞北社區的 3D 模型，給慈幼山友團「出隊必修課 2：環境介紹」做鏡頭導覽用。

## 怎麼看

1. 下載這個 repo：右上角 **Code → Download ZIP**，解壓縮。
2. 用電腦的 **Chrome 或 Edge** 直接打開 `index.html`。
3. 第一次載入約 30 秒～1 分鐘，地圖資料會即時從國土測繪中心和 OpenStreetMap 下載；之後會快取，開得比較快。

操作方式：

- 拖曳可以旋轉，滾輪或雙指可以縮放，右鍵拖曳可以平移。
- 下方按鈕可以飛到各個地點：縱谷全景、瑞北社區、大門口、校園全景、一樓教室、二樓、國幼班、禮堂。
- **▶ 播放導覽**：照必修2 的順序把 9 個鏡頭播一次。
- **標籤**：開或關地點標籤。
- **匯出影片**：輸出 1920×1080 的 MP4，可以選要不要加標籤。電腦版 Chrome／Edge 才能用，每段約 1–2 分鐘。

手機會自動切換成輕量模式，用的是解析度較低的影像、較少的樹和較小的陰影。想強制切換，可以在網址後面加 `?q=low` 或 `?q=high`。

## 內容怎麼做的

| 部分 | 來源 |
|---|---|
| 地面影像 | 內政部國土測繪中心 正射影像（PHOTO2），已自動去除「NLSC 2022」浮水印 |
| 房屋輪廓 | 國土測繪中心「通用電子地圖加值分棟建物框」（BUILDX），在瀏覽器裡描成多邊形 |
| 房屋高度 | 依面積推估 1–4 層，實際樓層沒有資料 |
| 道路、鐵路、地名 | OpenStreetMap |
| 地形 | Mapzen／AWS Terrain Tiles |
| 樹 | 從正射影像找出樹冠位置後隨機種樹，約 1/5 是檳榔樹 |
| 學校 | 社團雲端「瑞北國小場地平面圖.png」與分棟建物框對齊後手工建模，見 `docs/校園配置.md` |

Google 地圖和高德都沒有用來建模，前者條款不允許，後者在台灣的資料很少。
