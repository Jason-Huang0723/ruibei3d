# 校園配置

依據：社團雲端「瑞北國小場地平面圖.png」（OCR 讀出房間名稱），對齊國土測繪中心分棟建物框與正射影像，再參考舊版必修2 影片的口述。

## 座標

- 校地為 126 × 64.6 m 的矩形，長邊大致東西向，偏轉約 −14°。西側臨台9線（中正北路二段）。
- 程式裡的校地座標：原點在校地西北角，`u` 沿北側圍牆往東（公尺），`v` 往南（公尺）。
