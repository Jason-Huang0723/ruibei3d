## 門

- 每扇門是一片會轉的門板：`RB.DOORS[id] = {pv, base, phi}`，`RB.setDoor(id, k)`（k = 0 關、1 開）。教室門的 id 是 `樓層-房間名-第幾扇`，例如 `1-四教-0`。
- 場景步驟可以加 `open`／`close`（門 id 或陣列，或 `[id, 秒數]`）、`openAt`、`doorDur`。有門事件的場景一開始所有門都關著；沒有門事件的舊場景所有門都開著。

## 吉祥物

- `src/06a_mascot.js` 的 `RB.makeMascot()`：照山友吉祥物頭貼做的綠色圓角輪廓（擠出＋倒角、卡通材質、黑色描邊），臉是貼圖；手腳是膠囊形，白襪藍條紋、藍鞋。走路動作依移動距離計算。
