# 必修2 環境介紹影片（第四版）

風格改成跟必修1、必修3 一樣的暖色 3D 黏土風（書房、木牌標題、山友吉祥物、huninn 字型字幕、左上角句子編號）。共 32 句。

| 段落 | 內容 | 做法 |
|---|---|---|
| room1 | 書房標題（2-01）＋校門街景照（2-02，使用者 11/14 給的），照片放大接到 3D 校門口 | `src/sc_room2.js` |
| aer | 3D 校門口 → 升到空拍，依旁白推近北排、國幼班、操場（2-03～2-08） | 瑞北 3D 模型匯出的畫格當底圖（`RB.V2[0]`，匯出時用 `probe` 記錄每格標籤的螢幕座標），標籤由 `src/sc_aer.js` 畫 |
| table | 各間教室的用途（Excel 視窗，2-09～2-17） | `src/sc_table.js` |
| walk | 學校 → 男、女教師宿舍 → 火車橋 → 雜貨店（2-18～2-21）：使用者 11/14 錄的 Google 街景，約 4 倍速 | `src/sc_walk.js`（錄影裁掉 iPad 介面，時間對應表 K） |
| map | 空拍地圖：早上接小朋友（2-22～2-24）→ 回家路線（2-25～2-31）；地圖段的時間軸仍含 2-18～2-21，合成時從 2-22 前一秒開始用（tl.json 的 trim） | `src/sc_map2.js` |
| room2 | 書房結尾「出隊見！」（2-32） | `src/sc_room2.js` |

- 共用程式（core.js、m3d.js、props*.js、ui.js）沿用必修3 v4。
- `python3 make_tl.py` → `tl.json`（每段自己的時間軸；段落之間淡入淡出 0.6 秒）；`python3 build.py` → `index.html`。
- `node render.mjs <段> <起幀> <迄幀> out` 分段算圖；`python3 assemble4.py` 接起來並配上旁白。
- 地圖：國土測繪中心 PHOTO2 z16／z18／z20 拼接，`map/wm2.py` 去除「NLSC 2022」浮水印；`map/mapdata2.json` 是當地公尺座標（原點 23.5255, 121.379）的走路路線、圖釘、三條回家路線（照使用者畫的線，整體往西平移 57 公尺讓分岔點落在雜貨店）。
- 素材（街景照片、正射影像、配音）不放在這個 repo。
